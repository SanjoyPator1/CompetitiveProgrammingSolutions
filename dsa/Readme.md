# DSA 2025 - Complete Learning Roadmap

## Overview

This roadmap is designed to take you from basics to advanced DSA concepts, preparing you for technical interviews and competitive programming.

## Phase 1: Foundations (Weeks 1-4)

### 1. Arrays and Strings

- **Duration**: 1 week
- **Key Concepts**: Basic operations, indexing, iteration
- **Folder**: `01-arrays-strings/`

### 2. Two Pointers

- **Duration**: 3-4 days
- **Key Concepts**: Left-right pointers, fast-slow pointers
- **Folder**: `02-two-pointers/`

### 3. Sliding Window

- **Duration**: 4-5 days
- **Key Concepts**: Fixed and variable size windows
- **Folder**: `03-sliding-window/`

### 4. Hash Tables (Hash Maps/Sets)

- **Duration**: 1 week
- **Key Concepts**: O(1) lookups, collision handling
- **Folder**: `04-hash-tables/`

## Phase 2: Linear Data Structures (Weeks 5-7)

### 5. Linked Lists

- **Duration**: 1 week
- **Key Concepts**: Singly, doubly, circular linked lists
- **Folder**: `05-linked-lists/`

### 6. Stacks and Queues

- **Duration**: 1 week
- **Key Concepts**: LIFO, FIFO, monotonic stacks
- **Folder**: `06-stacks-queues/`

## Phase 3: Non-Linear Data Structures (Weeks 8-12)

### 7. Binary Trees

- **Duration**: 1.5 weeks
- **Key Concepts**: Traversals, properties, construction
- **Folder**: `07-binary-trees/`

### 8. Binary Search Trees

- **Duration**: 1 week
- **Key Concepts**: BST properties, operations
- **Folder**: `08-binary-search-trees/`

### 9. Heaps and Priority Queues

- **Duration**: 1 week
- **Key Concepts**: Min/max heaps, heap operations
- **Folder**: `09-heaps/`

### 10. Tries

- **Duration**: 4-5 days
- **Key Concepts**: Prefix trees, string matching
- **Folder**: `10-tries/`

## Phase 4: Graph Theory (Weeks 13-16)

### 11. Graphs - Basics

- **Duration**: 1 week
- **Key Concepts**: Representation, traversals (DFS, BFS)
- **Folder**: `11-graphs-basics/`

### 12. Advanced Graph Algorithms

- **Duration**: 2 weeks
- **Key Concepts**: Shortest path, MST, topological sort
- **Folder**: `12-advanced-graphs/`

### 13. Union Find (Disjoint Set)

- **Duration**: 4-5 days
- **Key Concepts**: Path compression, union by rank
- **Folder**: `13-union-find/`

## Phase 5: Advanced Techniques (Weeks 17-22)

### 14. Binary Search

- **Duration**: 1 week
- **Key Concepts**: Template, search space reduction
- **Folder**: `14-binary-search/`

### 15. Backtracking

- **Duration**: 1.5 weeks
- **Key Concepts**: Decision trees, pruning
- **Folder**: `15-backtracking/`

### 16. Dynamic Programming

- **Duration**: 2.5 weeks
- **Key Concepts**: Memoization, tabulation, state transitions
- **Folder**: `16-dynamic-programming/`

### 17. Greedy Algorithms

- **Duration**: 1 week
- **Key Concepts**: Local optima, proof techniques
- **Folder**: `17-greedy/`

## Phase 6: Advanced Topics (Weeks 23-26)

### 18. Intervals

- **Duration**: 4-5 days
- **Key Concepts**: Merging, overlapping intervals
- **Folder**: `18-intervals/`

### 19. Bit Manipulation

- **Duration**: 4-5 days
- **Key Concepts**: Bitwise operations, tricks
- **Folder**: `19-bit-manipulation/`

### 20. Math and Geometry

- **Duration**: 1 week
- **Key Concepts**: Number theory, computational geometry
- **Folder**: `20-math-geometry/`

### 21. Advanced Data Structures

- **Duration**: 1 week
- **Key Concepts**: Segment trees, Fenwick trees
- **Folder**: `21-advanced-ds/`
